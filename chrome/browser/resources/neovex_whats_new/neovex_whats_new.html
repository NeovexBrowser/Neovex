Neovex v1.1

Release — Stability Update

Version 1.1 introduces significant reliability updates to the browser's core update mechanisms.

Bug Fixes
What's New Tab Opened on Every Startup

After an update, the "What's New" tab was appearing every single time the browser was launched instead of only once. This was caused by the update system resetting the tracked version to 0.0.0 on each shutdown, making the browser believe a new update had always just been installed.

Fixed
Google & Other Sessions Logged Out After Each Session

The same version-reset bug was silently re-launching the update installer on every shutdown. Because the installer reinstalls the browser, it wiped cookies and session data — logging users out of Google and all other websites on every restart.

Fixed
Neovex Shield and all 1.0.1 features remain fully intact.

No features were changed or removed. This update is purely a stability fix — native ad-blocking, real-time analytics, and anti-fingerprinting all continue to work as designed.
